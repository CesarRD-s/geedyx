# @geedyx/web

GEEDYX web application.

Built with Next.js 16, React, TypeScript (strict), Tailwind CSS, and ESLint.

## Development

From the repository root:

```bash
pnpm dev:web
```

The app runs on `http://localhost:3000`.

## Repository context

This application runs inside the GEEDYX pnpm workspace. See the
[repository README](../../README.md) and [docs](../../docs) for architecture,
UI direction, and development workflow.

## Status

Default Next.js bootstrap only. No business functionality is implemented.
See [docs/UI.md](../../docs/UI.md) and [docs/PRODUCT.md](../../docs/PRODUCT.md).
